# antibody_hackathon

Work from the antibody design hackathon (HER2 / trastuzumab).

This `main` branch is intentionally empty apart from this README. The work lives on per-person branches:

| Branch | Contents |
| --- | --- |
| [`jakob`](../../tree/jakob) | Analysis scripts (`research_01` – `research_11`, `jakob_analyze.py`) and their outputs: ranked candidate lists, final and tiered panels, model coefficients |

```bash
git clone https://github.com/jakyric/antibody_hackathon.git
cd antibody_hackathon
git checkout jakob
```
