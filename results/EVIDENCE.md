**The number moves by up to 0.105 between seeds.** The
submitted designs span roughly 0.85 to 1.00, so the seed noise is
the same size as the spread between designs. Treat any difference
smaller than that as noise.

This matters beyond a caveat: it means the epitope column **cannot
rank these candidates either**. Like affinity, it separates our
designs from trastuzumab but not from each other.

## Reading the columns

**Affinity — the honest cell is empty.** All twenty designs sit at
exactly 4 CDRH3 mutations, so edit distance, the only scorer that tracks
measured affinity, is constant across them. Among 34 measured variants at
that same distance, no scorer we have beats chance. We cannot order these
ten on binding and we do not pretend to. See `results/audit/`.

**Epitope is a prediction, not a measurement.** It is contact overlap
computed from Boltz-2 structures, against a reference that is Boltz-2's
own prediction of the trastuzumab complex. The real answer is the lab's
competitive binding assay.

**Thermostability is a literature value on a different molecule.** VL
R66G gave +4.9 C on a trastuzumab scFv (Okazaki et al. 2023, ACS Omega
8(25):22945-22954, PMID 37396255). We have not measured it on ours, and
the -stab variants were never folded. Each is submitted alongside its
unmodified parent so the lab result can separate the two.

**Liabilities are the one column computed from the organisers' own
reference** rather than a model we fitted. Trastuzumab itself carries 8,
3 of them high severity, so the delta is what matters, not the count.
